Changing your mobile number or email needs a one-time code, and you are told about the change. EPFO staff will never ask you for a one-time code.

On the Account security page you can see where you are signed in. If you see activity you do not recognise, report it there and ask for account recovery.

An account-recovery request is reviewed by a security analyst. If it is approved, your last verified contact details are restored; nothing changes before the review.
