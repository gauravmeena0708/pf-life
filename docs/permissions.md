## Separation of duties (approval chains)

Maker and checker are always different people. Amount bands are illustrative configuration.

| Chain | Route | Source |
|---|---|---|
| claim_settlement | ≤ ₹50,000: `fo.da_accounts` → `fo.ss`<br>≤ ₹500,000: `fo.da_accounts` → `fo.ao`<br>≤ ₹2,500,000: `fo.da_accounts` → `fo.ss` → `fo.apfc`<br>> ₹2,500,000: `fo.da_accounts` → `fo.ao` → `fo.oic` | FIA 8(xvi); WSU 5.4.2 |
| claim_settlement_after_defreeze | ≤ ₹50,000: `fo.da_accounts` → `fo.ss` → `fo.ao`<br>≤ ₹500,000: `fo.da_accounts` → `fo.ao` → `fo.apfc`<br>> ₹500,000: `fo.da_accounts` → `fo.ao` → `fo.apfc` → `fo.oic` | FIA 8(xvi) |
| inoperative_settlement | `fo.da_accounts` → `fo.ss` → `fo.ao` → `fo.apfc` → `fo.oic` | WSU 5.1, 5.5 |
| joint_declaration | `employer.signatory` → `fo.da_accounts` → `fo.ss` → `fo.apfc` | JD 4.3-4.5, Table 3 |
| freeze_verification_member | `fo.da_accounts` → `fo.ss` → `fo.apfc` → `fo.oic` | FIA 8(vi-viii) |
| freeze_verification_establishment | `fo.da_compliance` → `fo.ss` → `fo.apfc` → `fo.oic` | FIA 8(ix-xii) |
