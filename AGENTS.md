# Agent UI Guidelines

When generating, modifying, or suggesting UI components for this project (EPFO POC), all agents must adhere to the following design principles to ensure a professional, government-grade aesthetic.

## 1. Theme and Color Palette
The application must strictly follow the official EPFO-inspired color theme:
- **Primary Colors:** Deep Blue and White. (e.g., Navy blue for headers, primary buttons, and strong text; pure white for backgrounds and surfaces).
- **Accents:** Golden and Red. (e.g., Golden for secondary accents, bottom borders of headers, or highlights; Red for critical actions, alerts, or specific banners).
- Do not introduce unrelated color schemes (e.g., pastel colors, neon, or modern startup-style gradients) unless explicitly requested.

## 2. Typography & Professionalism
- Maintain a highly professional, institutional appearance suitable for a government portal.
- Use readable, formal fonts (e.g., Georgia or similar serif fonts for headings, Trebuchet MS/Segoe UI/sans-serif for body text) as established in the base CSS.
- Ensure high contrast and clear visual hierarchy.

## 3. Component Design & Structure
- Keep UI components simple, pragmatic, and explicit. Avoid over-engineered, heavily animated, or overly trendy UI patterns. 
- Use clear borders, subtle shadows for depth, and straightforward layouts (e.g., grid systems for metrics and forms).
- Continue utilizing semantic HTML (e.g., `<main>`, `<aside>`, `<header>`) and ensure all components meet accessibility standards.
